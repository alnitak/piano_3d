# piano_3d

A 3D piano demo working on all platforms showcasing the integration of:

- [flutter_scene](https://pub.dev/packages/flutter_scene) for real-time 3D rendering.
- [flutter_soloud](https://pub.dev/packages/flutter_soloud) for low-latency audio playback.
- [soundfont_kit](https://github.com/alnitak/soundfont_kit) for SoundFont (SF2, SF3, and SFZ) instrument synthesis.

[Web demo](https://marcobavagnoli.com/piano_3d)
